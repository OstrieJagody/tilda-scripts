# Скрипты и стили для Tilda

- GitHub аккаунт: **OstrieJagody**
- Репозиторий: **tilda-scripts**

## Файлы
- [script.js](file:///C:/Users/espec/.gemini/antigravity/scratch/tilda-scripts/script.js) — ваш JavaScript код для Tilda.
- [style.css](file:///C:/Users/espec/.gemini/antigravity/scratch/tilda-scripts/style.css) — ваши кастомные стили CSS для Tilda.

## Код для вставки в Tilda (Настройки сайта ➔ Ещё ➔ HTML-код для вставки в HEAD)

```html
<!-- Стили и скрипты от OstrieJagody -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/OstrieJagody/tilda-scripts@main/style.css">
<script defer src="https://cdn.jsdelivr.net/gh/OstrieJagody/tilda-scripts@main/script.js"></script>
```

> **Совет по кэшированию:** jsDelivr кэширует файлы. Для мгновенного сброса кэша при разработке можно добавить версию к имени файла или использовать ссылку без задержки кэша:
> `https://raw.githack.com/OstrieJagody/tilda-scripts/main/script.js`
